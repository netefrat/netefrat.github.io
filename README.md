# netefrat.github.io

Personal homepage of Netalee Efrat — plain static HTML/CSS, no build step.

- `index.html` — all content (bio, publications, patents). To add a paper, copy an existing `<li>` block in the Publications section.
- `assets/img/pubs/` — publication thumbnails (~700px wide).
- `assets/img/prof_pic.jpg` — profile photo.
- `assets/css/style.css`, `assets/js/theme.js` — styling and light/dark toggle.

Preview locally: `open index.html`. Publish: commit and `git push`; GitHub Pages serves the `main` branch.
